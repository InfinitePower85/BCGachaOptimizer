BC Route Planner

Companion to BC Godfat's seed tracker.

1. Get tracks

Paste a bc.godfat.org link that includes a seed and event.

2. Roll viewer

One row per roll number, A/B tracks side by side. Colors follow BC Godfat's rarity scheme.

3. Your saved data

Stored in this browser only (IndexedDB). Export it as a backup, and import it on another device or after clearing browser data.

    4. Optimize

    Find the route that collects the most target units within a roll limit.
