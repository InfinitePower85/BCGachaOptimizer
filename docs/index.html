Datasets

Fetch from a bc.godfat.org link with your seed (a link without an event gets the banner Godfat shows by default), or import a previously exported file. Datasets are stored in this browser only (IndexedDB) -- export them as a backup, or to move them to another device. Pick one to use: the roll viewer and the optimizer both work from it.

    Whose units the roll viewer shows as icons, Collected shows as cards, and the optimizer offers as targets. Guessed from the dataset's banner when possible.
